WHAT TO LOOK FOR IN EVAL OUTPUT
---------------------------------
Good result:
    ep  1: reward=  4.21  collision=no   final_mode=STOP_HOLD
    ep  2: reward=  3.87  collision=no   final_mode=STOP_HOLD
    ...
    Collisions : 0/10
    Full stops : 9/10

This means the agent learned to brake and stop before the pedestrian.

Bad result (agent didn't learn or underfit):
    ep  1: reward= -12.3  collision=YES  final_mode=CRUISE
    Collisions : 8/10

This means the agent did not brake at all or braked wrong.
Most likely cause: only trained on one fixed scenario config — needs
more diverse episode randomization before it generalizes.


HOW TO TRAIN PPO (run after SAC as a comparison)
--------------------------------------------------
Create a train_ppo.py the same way as train_sac.py but with:
    from stable_baselines3 import PPO
    model = PPO("MlpPolicy", env, verbose=1,
                n_steps=2048, batch_size=64, n_epochs=10,
                learning_rate=2.5e-4, clip_range=0.2)
    model.learn(total_timesteps=500_000)   # PPO needs ~2.5x more steps
    model.save("ppo_aeb_500k")
PPO is on-policy so it needs more steps but is often more stable.

COMMON ISSUES
--------------
"Connection refused" on port 2000:
    CARLA is not running. Launch it and wait 20-30 seconds.

"ModuleNotFoundError: gymnasium":
    pip install stable-baselines3 gymnasium

Training crashes mid-run:
    Check CARLA is still running. Restart CARLA and re-run train_sac.py.
    The latest checkpoint in checkpoints/ is safe — it was saved before the crash.

Episode resets are slow (30-40 sec each):
    Normal. CARLA actor spawning takes time. Nothing to fix.

Walker fails to spawn (RuntimeError):
    Occasionally CARLA physics glitches. Just re-run train_sac.py.


KEY DESIGN DECISIONS (for reference / explaining to professor)
---------------------------------------------------------------
- Action space:    continuous float [0, 1] — how hard to brake each tick
- State vector:    5 inputs: speed, proximity to ped, TTC urgency,
                   previous brake command, hazard flag
- Reward:          safety penalty (collision) + comfort penalty (jerk)
                   + efficiency reward (moving toward goal)
- SAC chosen first: off-policy algorithm — reuses past experience via replay
                    buffer, critical for slow CARLA environment
- PPO second:       on-policy, used as comparison baseline
- Ramp limiter:     still active on top of RL output — agent outputs a
                    TARGET brake value, the ramp limiter smooths it
- RL insertion:     replaces only brake_target in lane_follow_step(),
                    all other logic (steering, STOP_HOLD, LiDAR) unchanged
